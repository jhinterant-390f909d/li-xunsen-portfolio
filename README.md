# Li Xunsen Portfolio

React + Vite portfolio site. The site is published with GitHub Pages from the `main` branch using GitHub Actions.

## Local preview

```sh
pnpm install
pnpm dev
```

## Production build

```sh
pnpm build
```

The GitHub Pages build uses `/li-xunsen-portfolio/` as its base path. Resume and source portfolio PDFs are intentionally excluded from the repository.
